## 2. 输入、会话与控制

- 输入内容是有序列表（文本段 + 附件段），预览与提交顺序一致；提交失败恢复原文与附件。
- `@` 引用只插入路径候选，不读取文件内容；引用按渲染时目录解析。
- 附件：暂存 → 校验 → 规范化 → 持久化 → 可提交引用；超限明确拒绝，不静默降级；回执一次性。
- 补全：文件 / `/` 命令 / 技能三类可区分；`Tab` 填入不执行，`Enter` 执行明确写下的内容；空结果显式提示。
- 命令面板只检索与转发，不自造命令目录。
- 会话列表 / 恢复 / 改名：来自官方查询；切根前释放旧认领与租约；冷会话改名先取写权限；加载失败不显示成空列表。
- 上下文占用显示官方投影值并标注非精确计费；压缩走官方行为，取消结果如实显示。
- 模型 / 推理强度 / 权限：只展示官方声明与预设；切换失败保留原值并显示原因；任何时刻可回答当前权限。
- 技能目录与项目规矩来源：展示官方快照，不复制第二份清单。

## 3. 终端、任务、Monitor、调度与子代理

- 内嵌终端：真实 PTY，经官方终端控制服务创建 / 附着 / 保留 / 释放 / 重命名 / 关闭；不自建 PTY；越序输入丢弃并报告；输出背压有界；退出释放 PTY。
- 任务：官方 jobs 的只读观察层；按绝对偏移非消费读取；停止只报「已请求停止 / 已结束」；不维护第二份任务表。
- 人工命令（`!`）：用户权限执行，输出作为合成上下文注入但不唤醒模型；首次使用提示系统权限。
- Monitor：有界预算；通知合并按时间窗与预算；`notify` 会唤醒模型并计费，默认 `quiet`；外部输出不能冒充授权。
- 调度：复用官方调度与存储；一个根会话一个 scheduler；租约拿不到报 `unsupported`；官方无暂停 / 恢复，停止只能删除，UI 如实呈现；投递非严格一次。
- 子代理：目录 / 活动 / 时间来自官方；续聊只走官方子代理提示接口；打断只用父代理打断；结束原因原样呈现；子地址订阅授权并回放，父/兄弟内容不得进入；导航栈与子草稿按地址保存。

## 4. 验收

- 附件、技能、会话恢复 / 压缩、模型 / 权限切换各用真实官方服务验证；不得用假数据或静态截图冒充。
- 终端：真实 PTY 创建、附着、输入、缩放、关闭；背压与越序输入有测试。
- 任务：查看输出不推进他人消费游标；停止 / 不存在 / 内部错误分类正确。
- Monitor：`notify` 默认关闭；开启有明确告知；预算触顶裁剪并标注。
- 调度：无租约不挂；停止即删除；投递语义在界面可读。
- 子代理：导航、续聊、打断、结束原因、内容隔离、容量拒绝 / 客户端取消分类。
- 跨会话：主 / 子地址内容隔离逐项核对；返回父会话不丢父草稿。
- 键位：各功能声明的键位在本份汇总，S03 冻结成表；不抢占输入态、覆盖层与终端面板。
