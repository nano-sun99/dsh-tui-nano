## 2. 包结构与安装

- 单一 npm 包，`bin` 暴露 `nano`（沿用命令名）；官方 `@deepseek-ai/*` 作为依赖，版本区间在 README 写明。
- 不引入平台相关二进制；无 native 依赖。
- 安装 / 升级 / 卸载均走 npm；数据根 `~/.dsh-tui-nano`；官方 `$DSH_HOME`、凭据、会话存储不动。
- 不写 profile 补丁、不依赖 `dsh --profile`（phase-0 回退时除外，回退路径也要写进 README）。
- 包内容不含测试夹具、证据截图与开发脚本；卸载说明可复制、可执行。
