# 鲸尾活动栏设计稿归档

保存日期：2026-11-01。与[原始界面样稿](../index.html)放在同一个 preview 目录下的独立子目录；原始 index.html、场景和截图不覆盖。

## 打开

双击或用本地浏览器打开 [index.html](index.html)。Chrome 为本次验证浏览器；无需启动临时服务、登录或联网。请保留整个 `whale-loading/` 目录，`index.html` 会读取旁边的 `assets.js`。

- 四款：官方原版晃动、翻转摆尾、左右摆尾、扭转摆尾。
- 顶部 Twist 对照保留源仓库原生组件与预览的同尺寸、同进度比较，可暂停或逐帧检查。
- “下一次模型请求”模拟一次随机抽取；同请求内切换测试场景不重抽。
- 正文已显示时隐藏活动图文，等待确认时显示静态提示；空闲仍保留一行。
- 100/60 列、深浅主题、减少动态效果及可编辑输入预览均保留。

## 保存的是哪个版本

保留本次对话最后确认的四款鲸尾、修正后的 Twist 原生播放方式，以及随后确认的请求级随机和正文显隐预览。仅将临时 `/files/` 资源读取换为本地素材包，文档链接换为仓内相对路径；不改变帧序、轮廓或周期。浏览器参考尺寸不构成终端尺寸承诺。

- [素材与来源指纹](manifest.json)：固定源提交、帧数、周期和帧序列摘要。
- [MIT 许可](LICENSE.status-rotator.txt)：Copyright (c) 2026 01Virex。
- `assets.js`：包含四款轮廓数据、源对照夹具与固定版本源组件；仅设计稿使用，不加入 Nano 产品依赖。源组件运行在演示 iframe，网络读取与存储由源演示夹具的内存替身接管。
- [归档打开检查](verification.json)：本次从本地文件打开后的检查结果，不沿用临时服务成功作为离线成功。
- [深色快照](archive-desktop.png)、[浅色窄屏快照](archive-narrow.png)：本次归档页截图，辅助定位；交互与动效以 HTML 为准。
