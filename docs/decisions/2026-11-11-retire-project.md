# ADR-20261111-retire-project：作废并归档 dsh-tui-nano 项目

- 状态：生效中
- 日期：2026-11-11
- 决策人：用户
- 适用范围：项目存续与维护
- 取代：无
- 被取代：无
- 决策来源：2026-11-11 本次会话。用户原话：「请你为我作废仓库，理由是使用同样的 deepseek-v4.1-flash-1017 对比 codex claude code等主流harness deepseek harness 在调研深度，方案设计和执行效率等方面体感上均有落后，此项目暂无继续维护价值」；作废方式选择「留墓碑后归档」。

## 决定

- dsh-tui-nano 停止维护；GitHub 仓库 `nano-sun99/dsh-tui-nano` 设为 archived（只读）。
- 归档前在中文 / 英文 README 顶部留作废说明，规格、ADR 与提交历史全部保留，不做删除。
- 未完成的 issue 与 PR 以「项目已作废」关闭，不再实施。

## 依据

- 用户判断（体感，未做系统基准测试）：同一模型 `deepseek-v4.1-flash-1017` 下，DeepSeek Harness 在调研深度、方案设计与执行效率上落后于 Codex、Claude Code 等主流 harness，项目无继续维护价值。
- 本记录只记录决策，不把上述体感升格为对 deepseek-harness 的客观评测结论。

## 否决了什么

- 继续维护、完成并发布 0.2.5。
- 直接删除仓库（会丢失规格、ADR 与历史）。
- 只做 GitHub 归档而不留任何作废说明。

## 接受的代价

- 未完成的工作就此冻结，包括流式渲染性能（#182 / #183 / #184）、调研流程调整（#179）、稳定性修复（#168 / #164）与输入区收尾（#110）等。
- 仓库公开可见但只读，不再接受 issue 与 PR。

## 允许重开的条件

- 用户明确要求恢复维护。
- DeepSeek Harness 的能力与体验出现可验证的实质提升，用户重新评估后决定重启。
